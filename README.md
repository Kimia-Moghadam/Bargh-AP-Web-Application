
Bargh-AP is a web application focused on electricity consumption, allowing users to log in, view base information, input data, and generate reports. The app integrates with APIs to fetch real-time data and incorporates various conditions and logic related to energy consumption. Built with React and styled with Tailwind CSS, the app offers a responsive and modern user experience.

Technologies Used:

React.js for frontend development

Tailwind CSS for custom styling

API integration for fetching consumption data

Conditional rendering based on energy consumption

User authentication and login system

Features:

Secure user authentication and login

Input and output pages for electricity data

Comprehensive reports on energy usage
